# HTB Write-ups

Personal write-ups and solve scripts for Hack The Box challenges and machines,
done as coursework for *Technologies for Cryptographic Systems Development*.

- [babyencryption](babyencryption/) — Crypto, Very Easy
- [noise-codex](noise-codex/) — Crypto, Easy
- [orion](orion/) — Machine, Easy (Linux)

Each folder has its own README with the approach, and the scripts/output used
to solve it. Flags are not included on purpose, since they are
challenge-specific secrets.
