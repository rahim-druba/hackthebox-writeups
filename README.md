# HTB Write-ups

My write-ups and solve scripts for Hack The Box challenges and machines, done as
coursework for *Technologies for Cryptographic Systems Development*.

- [babyencryption](babyencryption/) - Crypto, Very Easy
- [noise-codex](noise-codex/) - Crypto, Easy
- [orion](orion/) - Machine, Easy (Linux)

Each folder has its own README with the approach I took, plus the scripts and
output I used along the way. Flags are left out on purpose, since they're
challenge-specific secrets.
